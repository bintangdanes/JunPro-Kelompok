## Modul 1 - Ide Aplikasi

**Nama Produk:** TRASHURY (Trash + Treasury)

**Jenis Produk:** Aplikasi desktop Windows (WPF + MVVM), offline-first, untuk pengelola/operator bank sampah lokal (bukan konsumen)

**Latar Belakang & Permasalahan:**
Mayoritas pengurus bank sampah tingkat RW-kalurahan masih mencatat transaksi warga secara manual di buku tulis atau Excel, rentan hilang/salah hitung. Belum ada sistem otomatis untuk menghitung dampak lingkungan (estimasi CO2e) untuk pelaporan ke Dinas Lingkungan Hidup (DLH).

**Ide/Solusi:**
Aplikasi manajemen bank sampah lokal berbasis desktop dengan 6 fitur utama:
1. Master Data nasabah & kategori sampah
2. Transaksi Setoran otomatis
3. Penarikan Saldo & cetak riwayat buku tabungan
4. Dashboard Dampak Iklim (estimasi CO2e)
5. Laporan Bulanan (export CSV/PDF)
6. Klasifikasi Sampah berbasis AI (ONNX, offline)

**Analisis Kompetitor:**
- Smash.id dan Rapel — aplikasi mobile berbasis internet untuk penjemputan konsumen
- Metode manual (buku tulis, rumus Excel)

TRASHURY berbeda karena fokus offline-first untuk operator lokal, bukan konsumen.
